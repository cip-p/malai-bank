### Triage (2026-07-19)

**Maintainer decision: document as template-defined and deliberately unconstrained — do not type an envelope.** The seeded decisions prove no stable envelope exists: verdict key-sets differ per prompt template (`fraud-triage` → `decision`/`riskScore`; `transaction-categorisation` → `category`/`confidence`; `spending-insights` → `insight`; timed-out/errored decisions carry none). Typing would force the contract to track every prompt template and fights the MDR stance that the record stores what the model actually produced. Moved to `ready-for-agent`.

## Agent Brief

**Category:** enhancement
**Summary:** Document the Model Decision verdict as template-defined and deliberately unconstrained, in the contract and the MDR domain doc.

**Current behavior:**
`verdict` on the Model Decision view is a nullable untyped object (`additionalProperties: true`) with a one-line description ("Structured verdict; absent when unparseable or not produced"). Nothing states whether the looseness is intentional, so the webapp's formatted-JSON rendering is a guess.
